# APEX FITNESS — موقع النادي

موقع ثابت (HTML/CSS/JS) بالعربي ومتجاوب مع الجوال، جاهز للنشر على GitHub Pages.

## تعديل المعلومات
افتح `index.html` وابحث عن:
- `const SITE` : الرقم، واتساب، العنوان التفصيلي، رابط الخريطة، روابط إنستغرام وفيسبوك.
- `const PRODUCTS` : منتجات المتجر (حالياً منتجات تجريبية). اكتب السعر في `price` أو اتركه فارغاً ليظهر "السعر عند الطلب".

## النشر على GitHub Pages
Settings → Pages → Source: Deploy from a branch → Branch: `main` / root.
